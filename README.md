# Эмулятор командной оболочки

Прототип эмулятора оболочки с GUI на Tkinter, виртуальной
файловой системой на базе ZIP-архива и базовыми командами
UNIX-подобной командной строки.

## Возможности

- GUI-окно с заголовком вида `Эмулятор - [user@host]`
- Парсер аргументов с поддержкой одинарных и двойных кавычек
- Виртуальная файловая система (VFS) на основе ZIP-архива
- Все операции с VFS выполняются **в памяти** без распаковки
- Возможность **изменять** VFS в памяти (`cp`, `touch`)
- Параметры командной строки: `--vfs`, `--script`
- Стартовый скрипт с остановкой при первой ошибке
- Отладочный вывод параметров запуска в консоль
- Базовые команды `ls`, `cd`, `pwd`, `rev`
- Дополнительные команды `cp`, `touch`, `vfs-load`

## Команды

| Команда | Описание |
|---------|----------|
| `ls [путь]` | Показать содержимое каталога VFS |
| `cd [путь]` | Перейти в каталог VFS |
| `cat файл` | Показать содержимое файла из VFS |
| `pwd` | Показать текущий каталог |
| `rev файл` | Перевернуть строки файла из VFS |
| `cp источник назначение` | Скопировать файл внутри VFS |
| `touch файл` | Создать пустой файл в VFS |
| `vfs-init [путь]` | Заменить текущую VFS на VFS по умолчанию |
| `vfs-load путь` | Загрузить новую VFS из ZIP-файла |
| `exit` | Завершить работу эмулятора |

## Запуск

Без параметров:

    python src/firststage.py

С VFS-архивом:

    python src/firststage.py --vfs vfs/vfs_large.zip

С VFS и стартовым скриптом:

    python src/firststage.py --vfs vfs/vfs_large.zip --script scripts/demo_stage5.txt

## Параметры командной строки

- `--vfs PATH` — путь к ZIP-архиву с виртуальной файловой системой
- `--script PATH` — путь к стартовому скрипту с командами

## Тестовые VFS-архивы

В папке `vfs/` лежат три архива для тестирования:

- `vfs_small.zip` — минимальный: 1 файл в корне
- `vfs_medium.zip` — несколько файлов в 2 папках
- `vfs_large.zip` — 4 уровня вложенности, 8 файлов

## Тестовые скрипты

- `scripts/demo_stage4.txt` — команды этапа 4 (`ls`, `cd`, `pwd`, `rev`)
- `scripts/demo_stage5.txt` — команды этапа 5 (`cp`, `touch`, `vfs-load`)
- `scripts/demo_vfs_small.txt` — команды для маленькой VFS
- `scripts/demo_vfs_medium.txt` — команды для средней VFS
- `scripts/demo_vfs_large.txt` — команды для большой VFS
- `scripts/test_vfs_*.bat` / `.sh` — запуск эмулятора с разными VFS

## Особенности работы с VFS

Все изменения, сделанные командами `cp` и `touch`,
выполняются **только в памяти** эмулятора.
Исходный ZIP-архив на диске **не изменяется**.
При следующем запуске эмулятора VFS загружается из архива
в исходном состоянии.
